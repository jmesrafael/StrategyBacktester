# bb-core 1h paper bot: VPS instructions for later

Written Nov 5, 2026. This one file is all you need: the whole install bundle is embedded at the bottom, so it works from any PC.

**What this installs:** the 1h version of bb-core on simulated money ($250 start, same 5 coins, same risk steps as live). It runs beside the live bots with its own user, folder and service. It has no API keys and cannot place orders.

**What it does not touch:** the live BB-Core and I-Core bots, their keys, state or settings.

## Steps

### 1. PC: copy this file to the server

Replace `YOUR-VPS` with your usual server login.

```
scp HOME-VPS-INSTRUCTIONS.md YOUR-VPS:/tmp/
```

### 2. VPS: rebuild the bundle from this file and check it

```
cd /tmp
sed -n '/^BEGIN-BUNDLE$/,/^END-BUNDLE$/p' HOME-VPS-INSTRUCTIONS.md | sed '1d;$d' | base64 -d > lucidio-1h-paper.tar.gz
sha256sum lucidio-1h-paper.tar.gz
```

The hash must match the `SHA-256` line at the bottom of this file. If it doesn't, stop and copy the file again.

### 3. VPS: unpack and install

```
mkdir -p /tmp/lucidio-1h-new && tar -xzf lucidio-1h-paper.tar.gz -C /tmp/lucidio-1h-new
sudo bash /tmp/lucidio-1h-new/deploy-1h/install-1h-paper.sh
```

**Check the end of the output.** It must show the service running and say:

```
live bots' start times unchanged: YES
```

- If a step says `FATAL`, it stopped there and nothing later was changed. Send me the output.
- If it prints `WARNING live bots' state or start time CHANGED`, check the live bots right away.
- This installer has only been syntax-checked, not run on Linux, so this is its first real run.

### 4. Work PC: stop the local copy

In `D:\testing\Strat\bb-core-1h`, run `stop-paper.cmd`, so only the VPS keeps the paper record. Trades from the PC run do not carry over. The VPS starts a new record at $250.

### 5. Check it after the next hour

```
sudo bash /opt/lucidio-1h/deploy-1h/status.sh
```

You should see `service: active` and a log line saying `run finished ... 0 error(s)`.

## Everyday commands (VPS)

| What | Command |
|---|---|
| Results and last log lines | `sudo bash /opt/lucidio-1h/deploy-1h/status.sh` |
| Paper against backtest (for the Dec 4 review) | `sudo bash /opt/lucidio-1h/deploy-1h/status.sh compare` |
| Live log | `sudo journalctl -u lucidio-1h -f` |
| Stop / start | `sudo systemctl stop lucidio-1h` / `sudo systemctl start lucidio-1h` |
| Remove, keep the record | `sudo bash /tmp/lucidio-1h-new/deploy-1h/install-1h-paper.sh --uninstall` |
| Remove everything | `sudo bash /tmp/lucidio-1h-new/deploy-1h/install-1h-paper.sh --uninstall --purge` |

The remove commands need the unpacked folder. If `/tmp` was cleared, repeat steps 2 and 3's `tar` line first.

## What to expect

- No Telegram alerts, and it does not appear on the dashboard or ledger. Use the status command.
- About 20 trades a month, across 5 coins.
- About 5 public MEXC candle requests an hour, from the same server address as the live bots, with no API key.
- If you install more than 15 minutes after the hour, the first check may log a signal as too late to enter. That is normal.
- Paper charges no funding, so results run slightly high. In the 7-year backtest funding cost about 30R.
- Paper fills are simulated, so it does not test real fills or MEXC refusals.
